# ConectaEmpleo 💼

Prototipo de una plataforma de conexión laboral desarrollada en Java, orientada a facilitar el encuentro entre personas que buscan oportunidades de empleo y empresas que publican vacantes.

## 📌 Descripción

ConectaEmpleo es un proyecto académico desarrollado como una aplicación de escritorio con interfaz gráfica. El sistema permite gestionar diferentes tipos de usuarios, registrar información de candidatos y empresas, publicar vacantes y realizar búsquedas de oportunidades laborales de acuerdo con las habilidades de los usuarios.

El proyecto aplica conceptos de programación orientada a objetos, estructuras de datos, interfaces gráficas y manejo de archivos PDF.

## 🎯 Objetivo

Crear un prototipo que facilite la conexión entre candidatos y empresas mediante la gestión de perfiles, habilidades y oportunidades laborales.

## ⚙️ Funcionalidades

- 🔐 Inicio de sesión y gestión de roles.
- 👤 Registro y gestión de personas.
- 🏢 Registro y gestión de empresas.
- 💼 Publicación y gestión de vacantes.
- 🔎 Búsqueda de vacantes.
- 🤝 Coincidencia entre habilidades y requisitos de las vacantes.
- 📄 Carga y lectura de hojas de vida en formato PDF.
- 📚 Recomendación de capacitaciones según las habilidades.
- 📋 Postulación de candidatos a vacantes.
- ✅ Selección de candidatos por parte de las empresas.
- 📊 Módulo de análisis del crecimiento del empleo informal.

- Clases y objetos.
- Encapsulamiento.

- Manejo de eventos.

- Lógica de coincidencia de habilidades.

## 📄 Estado del proyecto

Actualmente, ConectaEmpleo se encuentra en etapa de prototipo funcional.

La información se maneja principalmente durante la ejecución de la aplicación. Como parte de las futuras mejoras se plantea implementar persistencia de datos mediante una base de datos.

## 🚀 Próximas mejoras

- Integración con una base de datos.
- Persistencia de usuarios, empresas y vacantes.
- Mejoras en el sistema de autenticación.
- Desarrollo de un backend o API.
- Mejoras en el sistema de coincidencia entre candidatos y vacantes.
- Mejor gestión y almacenamiento de hojas de vida.
